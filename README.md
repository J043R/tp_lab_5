# News / Vacancy Parser - Scrum Simulation

Проект рассматривается как продукт - приложение для парсинга новостей или вакансий
из одного источника с сохранением данных в CSV-файл.
В рамках лабораторной работы моделируется Scrum-процесс разработки данного продукта.
Для этого используется Product Backlog и Sprint Backlog в виде GitHub Issues.

## Sprint Review

В ходе спринта были закрыты задачи по выбору источника данных
и определению формата CSV-выгрузки.
По итогам спринта была сформирована базовая концепция продукта.
Задачи по проектированию архитектуры и сценарию запуска
не были завершены и перенесены на следующий спринт.

## Sprint Retrospective

Планирование спринта и распределение задач прошло успешно.
Основные сложности возникли при оценке объёма архитектурных решений.
В следующем спринте необходимо более детально декомпозировать задачи
и уточнять критерии готовности.
