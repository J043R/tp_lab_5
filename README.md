# News / Vacancy Parser - Scrum Simulation

Проект рассматривается как продукт - приложение для парсинга новостей или вакансий
из одного источника с сохранением данных в CSV-файл.
В рамках лабораторной работы моделируется Scrum-процесс разработки данного продукта.
Для этого используется Product Backlog и Sprint Backlog в виде GitHub Issues.
